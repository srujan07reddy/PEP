# Product Engineering Platform (PEP)

**Domain-Agnostic AI-Assisted ERP Evolution Framework**

## Vision
This framework is NOT an ERP and DOES NOT replace existing ERP systems. Instead, it is an **AI-assisted Engineering Governance Framework** that continuously evaluates, governs, analyzes, explains, and evolves existing ERP systems across any business domain. The framework behaves as an AI Chief Engineering Advisor capable of guiding ERP evolution through governance-driven analysis, explainable reasoning, intelligent prioritization, and strategic engineering roadmaps.

## 🚀 Key Features & Functionalities

### 1. Code & Architecture Intelligence
- **Code Knowledge Graph**: Leverages Tree-sitter and Neo4j to parse codebases, generate dependency graphs, and infer system architecture.
- **Semantic Code Retrieval**: Uses Qdrant for vector similarity search, enabling deep contextual engineering memory.
- **Document Intelligence**: Integrates Docling, Tika, and Unstructured for extracting insights from complex unstructured organizational documentation.

### 2. Multi-Agent Workflows
- **Autonomous Agents**: Powered by LangGraph to route engineering tasks, run governance checks, and manage state over complex reasoning loops.
- **Governance & Linting Agents**: Includes generic linter agents for automated compliance, security, and best-practice enforcement (e.g., Ruff and MyPy integrations).

### 3. Core Evolution Engines
- **Business System Discovery Engine**: Discovers business modules, entities, relationships, workflows, APIs, and architecture without assuming any specific domain.
- **Governance Engine**: Evaluates governance maturity, approval chains, segregation of duties, and decision transparency.
- **Workflow Engine**: Detects business bottlenecks, duplicate workflows, and automation opportunities across any industry process.
- **AI Opportunity Engine**: Discovers AI use-cases based on dynamically loaded Domain Packs.
- **Compliance Engine**: Dynamically loads compliance standards tailored to specific industries.
- **Engineering Decision Board**: Merges findings, resolves conflicts, calculates priorities, and builds a unified topological dependency graph.
- **ERP Maturity Engine**: Generates an Overall ERP Maturity Score (Initial to Autonomous) across categories like Architecture, Technical Debt, and AI Readiness.

### 4. Domain Packs
The core Evolution Engine remains strictly domain-independent. Specialized rules, workflows, AI opportunities, and industry standards are loaded dynamically via pluggable **Domain Packs** supporting industries such as: Education, Healthcare, Government, Manufacturing, Retail, Banking, and Enterprise.

### 5. Explainable AI (XAI)
Every recommendation generated by the platform ensures explainability by answering:
- *Why was it suggested?*
- *What is the evidence or policy reference?*
- *What is the expected business value?*
- *What are the future dependencies?*

## 🛠️ Technology Stack
- **Backend**: Python, FastAPI, Uvicorn
- **Frontend**: React / Next.js ecosystem
- **AI & ML**: LangGraph, Sentence-Transformers, PyTesseract, Torch
- **Databases & Vector Stores**: Neo4j (Graph Database), Qdrant (Vector Database)
- **Code Analysis**: Tree-sitter, Semgrep
- **Data Parsing & Processing**: Docling, Unstructured, Tika, Pandas

## 📊 Outputs & UI Interfaces
- **ERP Evolution Blueprint**: A comprehensive roadmap detailing the current state, gap analysis, priority matrices, and implementation phases with estimated costs and business impact.
- **Platform Console**: A React-based web dashboard allowing CIOs, CTOs, IT Administrators, Architects, and Compliance Officers to view real-time governance insights, codebase health, and domain-specific engineering recommendations.

## ⚙️ Getting Started
Ensure you have Python 3.x and Node.js installed.

1. **Install Backend Dependencies**:
   ```bash
   pip install -e .
   ```
2. **Start Backend Server**:
   ```bash
   cd apps/platform_console/backend
   python -m uvicorn main:app --reload
   ```
3. **Start Frontend Client**:
   ```bash
   cd apps/platform_console/frontend
   npm install
   npm run dev
   ```

*(Please refer to the `ROADMAP.md` for our current integration phase and future milestones like Semgrep and OpenHands).*
